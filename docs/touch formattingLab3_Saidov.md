# Текстовое форматирование и блоки кода

## Задание: Комментированная программа на C#
Создайте консольное приложение на C#, которое демонстрирует базовую математическую логику и ввод-вывод данных.

### Требования к программе:
1. **Имя файла:** `FormatDemo.cs`
2. **Логика:**
   * Запрашивает у пользователя два числа;
   * Выполняет их сложение;
   * Выводит результаты в форматированном виде.

### Реализация кода:

```csharp
using System;

class FormatDemo
{
    static void Main()
    {
        // Запрос первого числа у пользователя
        Console.Write("Введите первое число: ");
        double number1 = Convert.ToDouble(Console.ReadLine());

        // Запрос второго числа у пользователя
        Console.Write("Введите второе число: ");
        double number2 = Convert.ToDouble(Console.ReadLine());

        // Вычисление суммы чисел
        double sum = number1 + number2;

        // Вывод результата на экран
        Console.WriteLine(\$"**Результаты операций: {sum}**");
    }
}
```
