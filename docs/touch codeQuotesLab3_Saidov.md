# Блоки кода и цитаты

## Примеры работы с кодом

### Встроенный (inline) код
Для проверки текущего состояния файлов и индекса в Git используется команда `git status`.

### Многострочный блок кода с подсветкой синтаксиса (Python)
```python
def greet(name):
    print(f"Hello, {name}! Добро пожаловать в Markdown.")

greet("Разработчик")
```
