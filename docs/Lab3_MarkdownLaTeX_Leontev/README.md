## Теоретические сведения
> **Markdown** — это простой инструмент для писателей и программистов. Текст, написанный на Markdown, можно сразу же читать, не отвлекаясь на теги разметки.
> 
>> **LaTeX** — мощная издательская система, незаменимая, когда в документацию нужно внедрить сложные математические расчеты, матрицы или интегралы.

## Примеры форматирования текста
При оформлении отчетов часто требуется выделять важные элементы:
* Это **полужирный текст** для акцентирования внимания.
* Это *курсивный текст* для выделения терминов.
* Это ~~зачёркнутый текст~~ для обозначения устаревших данных.
* А это `моноширинный шрифт` для написания команд вроде `git status`.

## Математические формулы (LaTeX)
В документацию проекта можно легко добавлять математические вычисления.

**Пример в тексте (Inline):**
Сумма квадратов катетов равна квадрату гипотенузы: $a^2 + b^2 = c^2$.

**Выделенный блок формулы (Block):**
$$
f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2\pi i \xi x}\,d\xi
$$
