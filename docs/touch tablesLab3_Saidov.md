# Таблицы в Markdown

Ниже представлена таблица основных команд Git, используемых при выполнении лабораторной работы, с выравниванием по разным краям:

| Функция (Влево) | Команда Git (Центр) | Описание возможностей (Вправо) |
| :--- | :---: | ---: |
| Создание репозитория | `git init` | Инициализация нового локального репозитория |
| Просмотр состояния | `git status` | Показывает изменённые и неотслеживаемые файлы |
| Индексация файлов | `git add .` | Добавляет все изменения в текущей папке в индекс |
| Фиксация изменений | `git commit -m "msg"` | Создает коммит с текстовым описанием изменений |
| Отправка на GitHub | `git push` | Загружает локальные коммиты на удаленный сервер |
