## Alert-блок GitHub
> [!TIP]
> Совет по использованию: Для экранирования специальных символов в Markdown используйте обратный слэш `\`. Например, чтобы написать звёздочки без применения курсива, напишите `\*курсив\*`.

## Escape-символы
\# Это не заголовок, так как символ решетки заэкранирован.
\*Это просто текст со звёздочками, а не курсив\*
