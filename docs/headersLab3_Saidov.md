# Лабораторная работа №3

## Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Что такое Markdown?
Markdown — это лёгкий язык разметки с простым и интуитивно понятным синтаксисом. Он позволяет форматировать обычный текст так, чтобы его было удобно читать как в исходном виде, так и после преобразования в красивую HTML-страницу.

#### Где он применяется?
Markdown находит широкое применение в IT-индустрии:
* Оформление файлов `README.md` в репозиториях GitHub, GitLab и Bitbucket.
* Написание технической документации (например, в база знаниях Obsidian или Notion).
* Публикация статей на форумах для разработчиков (Хабр, Stack Overflow).
* Ведение блогов и создание статических сайтов.

#### Зачем он нужен разработчикам?
Разработчикам Markdown необходим для быстрого написания понятной документации к коду без отвлечения на сложные визуальные редакторы (вроде MS Word). Он экономит время, легко отслеживается через системы контроля версий (Git) и обеспечивает единообразный стиль документов во всей команде.
